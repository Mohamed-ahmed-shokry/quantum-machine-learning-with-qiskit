# Legacy notebooks

These notebooks are retained for historical context only. They use APIs from
pre-1.0 Qiskit releases, including `execute`, `Aer` imports from `qiskit`,
`QuantumInstance`, and the retired `IBMQ` provider.

They are not part of the tested learning path and are not expected to execute
with the dependencies declared by this project. Use the numbered notebooks in
the parent directory for maintained examples.

> **Security note:** `qlerning.ipynb` previously contained a plaintext IBM
> Quantum token. The token was removed from the current tree, but repository
> history must be treated as exposed. Revoke the old credential before using
> any IBM Quantum account associated with it.
